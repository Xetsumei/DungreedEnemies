# DungreedEnemies 1.2.9

[最新版ZIPをダウンロード](https://github.com/Xetsumei/DungreedEnemies/releases/latest)

[한국어](README_ko.md) · [English](README_en.md) · [日本語](README_jp.md) · [中文](README_zh.md)

ダングリードの通常モンスター90種類とボスを、セフィリアの見下ろし型戦闘に移植するAddOnです。中ボス6種類も各階層で自然出現するようになりました。

## 主な機能

- 通常の出現枠ごとに、バニラの敵とその階層のダングリードの敵を50:50で選びます。各部屋で半数になる保証ではありません。
- 中ボスはその階層のバニラ中ボスと等確率で選ばれ、元の中ボスの能力値と報酬を使用します。1・2・3・5階はバニラ/DEが各1/2、4階はバニラ/ライオナ/リヴナが各1/3です。以下はEMの禁止設定やランダマイザー適用前の構成です。

| 階層 | 追加中ボス |
| --- | --- |
| 1 | 監獄王の将軍「アステリオス」 |
| 2 | 屈服した戦士「スクィアタ」 |
| 3 | 強化されたロボット「インパルスジャンパー」 |
| 4 | コロソ・ボカ「ライオナ」・魔女剣「リヴナ」 |
| 5 | 方舟の現身「ナグルファル」 |

- ハードモードの**Blood Festival（敵の命中時回復）**によるDEの回復は、**個体ごとに2秒に1回**です。最初の有効な命中では即座に回復し、連続弾幕や複数プレイヤーへの命中は攻撃者のクールダウンを共有します。回復量とボス・マルチプレイ補正は元の計算を維持します。バニラの敵や他の回復効果には影響しません。
- EMを併用すると通常モンスターと中ボスを一覧から禁止できます。EM・QoL・ModMakerは必須ではありません。
- 名前は韓国語・英語・日本語・簡体字中国語に対応し、ゲーム言語に従います。
- スライムメーカー・アルシャ・エリチャ・エルター・エレ・デヴァナは、まだ自然出現しません。

## インストール

ゲームを終了し、`Sephiria/AddOns/DungreedEnemies`を作成してZIPの内容を展開してください。その直下に`metadata.json`・`DungreedEnemies.dll`・`DungreedEnemies.pak`・`Libs`を置きます。手動更新も同じ場所に上書きしてください。

## 自動アップデート

ゲームに入ると新しいバージョンを確認し、ロビーで［今すぐアップデート・後で通知・このアップデートをスキップ］を選べます。今すぐアップデートを押すとダウンロードしてゲームを再起動します。ラン中は自動でウィンドウを開いたり終了したりしません。

`/de update`で手動確認できます。`/de update off`で自動確認をオフにし、`/de update on`で再びオンにできます。スキップしたバージョンも手動確認で表示できます。

ファイルは検証後に適用し、設定は引き継ぎます。Libsが変更されたバージョンはZIPをダウンロードし、ゲームを終了してから上書きしてください。

この機能がない旧版では、最初の1回は新しいZIPを手動でインストールしてください。
