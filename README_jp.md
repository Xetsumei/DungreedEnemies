# DungreedEnemies 1.1.1

[한국어](README_ko.md) · [English](README_en.md) · [日本語](README_jp.md) · [中文](README_zh.md)

ダングリードの通常モンスター90種類とボス8種類をセフィリアの見下ろし型戦闘に移植するAddOnです。通常モンスターは階層別の候補から自然出現します。デヴァナは自然出現の候補から除外されています。

## 1.1.1 — 2026-09-15

- 配布版の更新履歴は `patchlog` ファイルで確認できます。

## 主な機能

- 通常の出現枠ごとに、バニラの敵とその階層のダングリードの敵を50:50で選びます。各部屋で半数になる保証ではありません。
- 専用設定画面はありません。EMがあれば一覧から禁止できます。EM・QoL・ModMakerは必須ではありません。
- 通常モンスター・ボス・付属個体の名前107件が韓国語・英語・日本語・中国語に対応し、ゲーム言語に従います。
- F8テスト機能は無効です。

## インストール

ZIPを`Sephiria/AddOns/DungreedEnemies`に展開してください。`metadata.json`・DLL・`Libs`を同じフォルダーに保管してください。 `DungreedEnemies.pak`も一緒に保管してください。

## 自動アップデート

ゲームに入ると新しいバージョンを確認し、ロビーで［今すぐアップデート・後で通知・このアップデートをスキップ］を選べます。今すぐアップデートを押すとダウンロードしてゲームを再起動します。ラン中は自動でウィンドウを開いたり終了したりしません。

`/de update`で手動確認できます。`/de update off`で自動確認をオフにし、`/de update on`で再びオンにできます。スキップしたバージョンも手動確認で表示できます。

ファイルは検証後に適用し、設定は引き継ぎます。Libsが変更されたバージョンはZIPをダウンロードし、ゲームを終了してから上書きしてください。

この機能がない旧版では、最初の1回は新しいZIPを手動でインストールしてください。

[更新履歴](patchlog_jp.md)

ゲームに入り、キャラクターとチャット表示の準備ができると、`[DungreedEnemies] 最新バージョンです。` または新版の通知が一度表示されます。更新ウィンドウは他のモッドのウィンドウが閉じてから開きます。自動確認をオフにした場合やスキップした版では自動の更新ウィンドウは出ません。
