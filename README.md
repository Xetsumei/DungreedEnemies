# DungreedEnemies 1.2.9

[최신 버전 ZIP 다운로드](https://github.com/Xetsumei/DungreedEnemies/releases/latest)

[한국어](README_ko.md) · [English](README_en.md) · [日本語](README_jp.md) · [中文](README_zh.md)

던그리드의 일반 몬스터 90종과 보스를 세피리아의 탑뷰 전투로 이식하는 AddOn입니다. 이제 중간 보스 6종도 각 층에서 자연 출현합니다.

## 주요 기능

- 일반 소환 자리마다 기존 몬스터와 해당 층 던그리드 몬스터를 50:50으로 선택합니다. 방마다 정확히 절반을 보장하지는 않습니다.
- 중간 보스는 해당 층 바닐라 중간 보스와 균등 확률로 선택하며, 원래 중간 보스의 능력치와 보상을 사용합니다. 1·2·3·5층은 바닐라/DE가 각각 1/2, 4층은 바닐라/라이오나/리브나가 각각 1/3입니다. 아래는 EM 밴·랜더마이저를 적용하기 전 기본 구성입니다.

| 층 | 추가 중간 보스 |
| --- | --- |
| 1 | 감옥왕의 장군 아스테리오스 |
| 2 | 굴복한 전사 스퀴아타 |
| 3 | 강화된 로봇 임펄시브 점퍼 |
| 4 | 코로소 보카 라이오나 · 마녀검 리브나 |
| 5 | 방주의 현신 나글파르 |

- 하드모드 **피의 축제**는 DE 개체마다 **2초에 한 번** 회복합니다. 첫 유효 적중은 즉시 회복하며, 연속 탄막·여러 플레이어 적중은 같은 공격자의 쿨다운을 공유합니다. 회복량과 보스·멀티플레이 보정은 원본을 따릅니다. 바닐라 몬스터와 다른 회복 효과에는 영향을 주지 않습니다.
- EM을 함께 사용하면 일반 몬스터와 중간 보스를 밴할 수 있습니다. EM·QoL·ModMaker는 필수가 아닙니다.
- 이름은 한국어·영어·일본어·중국어 간체를 지원하며 게임 언어를 따릅니다.
- 슬라임 메이커·아르샤·에리차·에르타 알레와 데바나는 아직 자연 출현하지 않습니다.

## 설치

게임을 종료한 뒤 `Sephiria/AddOns/DungreedEnemies` 폴더를 만들고 ZIP의 내용물을 그 안에 풀어 주세요. 해당 폴더 바로 아래에 `metadata.json`, `DungreedEnemies.dll`, `DungreedEnemies.pak`, `Libs`가 있어야 합니다. 수동 업데이트도 같은 위치에 덮어쓰면 됩니다.

## 자동 업데이트

게임에 들어가면 새 판을 확인하고, 로비에서 [지금 업데이트 · 나중에 다시 알림 · 이 업데이트 건너 뛰기]를 묻습니다. 지금 업데이트를 누르면 받아서 게임을 다시 켭니다. 런 도중에는 자동으로 창을 띄우거나 게임을 끄지 않습니다.

`/de update`로 직접 확인할 수 있습니다. `/de update off`는 자동 확인을 끄고, `/de update on`은 다시 켭니다. 건너뛴 판도 직접 확인하면 다시 볼 수 있습니다.

받은 파일은 검증한 뒤 적용합니다. 설정은 그대로 남습니다. Libs가 바뀐 판은 안내에 따라 ZIP을 받아 게임을 끈 뒤 덮어써 주세요.

이 기능이 없는 구버전에서는 처음 한 번 새 ZIP을 직접 설치해야 합니다.

[업데이트 기록](patchlog_ko.md)

게임에 들어와 캐릭터와 채팅창이 준비되면 `[DungreedEnemies] 최신 버전입니다.` 또는 새 업데이트 알림이 한 번 표시됩니다. 새 판의 업데이트 창은 다른 모드의 창이 닫힌 뒤 차례로 열립니다. 자동 확인을 껐거나 해당 판을 건너뛴 경우에는 자동 업데이트 창이 나타나지 않습니다.
