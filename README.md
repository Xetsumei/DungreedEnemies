# DungreedEnemies 1.1.1

- README와 업데이트 기록은 GitHub 저장소에서 확인할 수 있습니다. Release ZIP에는 포함하지 않습니다.


[한국어](README_ko.md) · [English](README_en.md) · [日本語](README_jp.md) · [中文](README_zh.md)

던그리드의 일반 몬스터 90종과 보스 8종을 세피리아 탑뷰 전투로 이식하는 AddOn입니다. 일반 몬스터는 층별 후보에서 자연 출현합니다. 보스 8종 중 데바나는 자연 출현 후보에서 제외되어 있습니다.

## 1.1.1 — 2026-09-15

- 배포본의 업데이트 기록은 `patchlog` 파일에서 확인할 수 있습니다.

## 주요 기능

- 일반 소환 자리마다 기존 몬스터와 해당 층 던그리드 몬스터를 50:50으로 선택합니다. 방마다 정확히 절반을 보장하지는 않습니다.
- 별도 설정창이 없습니다. EM을 함께 사용하면 해당 몬스터를 목록에서 밴할 수 있습니다. EM · QoL · ModMaker는 필수가 아닙니다.
- 일반 몬스터 · 보스 · 부속 개체의 이름 107개가 한국어 · 영어 · 일본어 · 중국어를 지원하며 게임 언어를 따릅니다.
- F8 테스트 기능은 꺼져 있습니다.

## 설치

ZIP을 풀어 `DungreedEnemies` 폴더를 `Sephiria/AddOns` 아래에 넣으세요. `DungreedEnemies/metadata.json`과 DLL, `Libs`가 같은 폴더 안에 있어야 합니다. `DungreedEnemies.pak`도 함께 두세요.

## 자동 업데이트

게임에 들어가면 새 판을 확인하고, 로비에서 [지금 업데이트 · 나중에 다시 알림 · 이 업데이트 건너 뛰기]를 묻습니다. 지금 업데이트를 누르면 받아서 게임을 다시 켭니다. 런 도중에는 자동으로 창을 띄우거나 게임을 끄지 않습니다.

`/de update`로 직접 확인할 수 있습니다. `/de update off`는 자동 확인을 끄고, `/de update on`은 다시 켭니다. 건너뛴 판도 직접 확인하면 다시 볼 수 있습니다.

받은 파일은 검증한 뒤 적용합니다. 설정은 그대로 남습니다. Libs가 바뀐 판은 안내에 따라 ZIP을 받아 게임을 끈 뒤 덮어써 주세요.

이 기능이 없는 구버전에서는 처음 한 번 새 ZIP을 직접 설치해야 합니다.

[업데이트 기록](patchlog_ko.md)

게임에 들어와 캐릭터와 채팅창이 준비되면 `[DungreedEnemies] 최신 버전입니다.` 또는 새 업데이트 알림이 한 번 표시됩니다. 새 판의 업데이트 창은 다른 모드의 창이 닫힌 뒤 차례로 열립니다. 자동 확인을 껐거나 해당 판을 건너뛴 경우에는 자동 업데이트 창이 나타나지 않습니다.
